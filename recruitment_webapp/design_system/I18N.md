# I18N — VI | EN

## 1. Default
- Default UI language: **Tiếng Việt**.
- Language switcher: **`VI | EN`**.
- Vị trí: góc trên bên phải của app header/top utility area.

## 2. Scope dịch
Phải chuyển đồng bộ:
- sidebar/menu;
- page title/description;
- buttons/actions;
- table headers;
- filters/search placeholder;
- status labels;
- drawer/modal/popup;
- form labels/helper/error;
- confirmation/warning/toast;
- Login;
- Preview trên màn hình;
- empty/loading states.

## 3. Không tự dịch business content
Không tự động dịch:
- HR Note;
- Interviewer comment;
- Candidate-entered text;
- Demo Topic;
- file name;
- master data value nếu database chỉ có một label.

Nếu cần bilingual master-data value sau này, đó là business/data decision riêng.

## 4. State persistence
Sau khi user đổi VI/EN:
- ghi preference local storage hoặc user preference;
- lần đăng nhập tiếp theo khôi phục lựa chọn;
- nếu chưa có preference → VI.

## 5. Layout resilience
- Không dùng hard-coded width dựa riêng tiếng Việt.
- Button/label đủ chỗ cho English copy hoặc wrap hợp lý.
- Status badge là ngoại lệ: width đồng nhất theo status group và được tính theo label dài nhất trong VI/EN của group.

## 6. Status label recommendation
Để badge không quá rộng, dùng English UI label ngắn nhưng rõ:
- Available
- Scheduled
- Awaiting
- Confirmed
- Cancelled

Không kéo dài thành câu mô tả nếu enum/status name đã đủ rõ.

## 7. Accessibility
Switcher:
- keyboard focusable;
- có `aria-label` phù hợp;
- current language có selected state rõ;
- không dùng flag icon để đại diện ngôn ngữ.

## 8. Date / number formatting
- Dùng locale-aware formatter (`Intl.DateTimeFormat`, `Intl.NumberFormat` hoặc equivalent), không hard-code chuỗi format rải rác trong component.
- Khi VI: label/ngày theo Vietnamese locale presentation.
- Khi EN: label/ngày theo English locale presentation.
- Business timezone vẫn theo Technical Handover (`Asia/Ho_Chi_Minh`); đổi ngôn ngữ không đổi timezone nghiệp vụ.
- Date-only values (ví dụ ngày sinh) không được chuyển timezone.

## 9. URL/state
Nếu filter/sort/page/tab được encode trong URL, đổi ngôn ngữ phải giữ nguyên các query params/state nghiệp vụ đó.
