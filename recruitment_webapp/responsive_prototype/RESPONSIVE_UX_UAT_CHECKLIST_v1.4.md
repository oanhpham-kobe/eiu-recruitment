# Responsive UX-UAT Checklist v1.4

- [ ] Status badges feel compact; they no longer occupy the whole value column.
- [ ] `Chờ xác nhận`, `Đã xác nhận`, `Sẵn sàng`, `Hủy` use the same compact status width.
