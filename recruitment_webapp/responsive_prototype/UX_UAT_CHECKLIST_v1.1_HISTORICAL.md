# UX-UAT Checklist — Clickable Prototype v1.0

Đánh dấu: `PASS / ADJUST / BLOCKER`.

| ID | Flow | Câu hỏi cần kiểm tra | Kết quả | Ghi chú |
|---|---|---|---|---|

| UX-08 | Interview | Cảnh báo conflict interviewer có đủ rõ và đúng lúc không? |  |  |

| UX-16 | Density | Font, row height, toolbar có quá dày/nhỏ khi HR dùng lâu không? |  |  |
